At a glance

This is a true loop: it closes back on its own start point, so there's no return leg to plan; the 186 m of climbing is steady rather than steep, a fair ask for most fit dogs.

Where to start

Mapped start suggestion — Bus stop Andalo, 3 m from the route. Check current access before travelling.
